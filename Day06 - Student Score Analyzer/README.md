# DayXX - Student Score Analyzer

## Objective

Practice reading data from external TXT files and performing operations on lists and numerical values in Python.

## Instructions

1. Create a file called `students.txt` and paste the following data inside:

   ```txt
   Alex,78
   Maria,92
   John,65
   Sophie,88
   Luca,55
   Emma,73
   Daniel,99
   Sara,81
   ```

2. Read the file and store all students inside a Python list.

3. Calculate the average score of all students.

4. Display the student with the highest score.

5. Create a new file called `passed_students.txt` containing only students with a score greater than or equal to 70.

6. Sort all students by score from highest to lowest.

7. Save the sorted result into a file called `sorted_scores.txt`.
